# KR2VI Dub

Tiện ích Chrome xem video YouTube với giọng lồng tiếng Việt: lấy phụ đề (Hàn/Nhật/Trung/Anh) → dịch sang tiếng Việt → đọc thành tiếng đúng thời điểm trên video. Chạy trên Windows, macOS và Linux.

## Cài đặt

1. Vào trang repo GitHub → **Code** → **Download ZIP**, rồi giải nén vào một thư mục cố định (đừng xoá hoặc di chuyển sau khi cài).
2. Mở `chrome://extensions` và bật **Developer mode** (góc trên bên phải).
3. Bấm **Load unpacked** và chọn thư mục `kr2vi-dub` (thư mục chứa file `manifest.json`).
4. Mở video YouTube bất kỳ có phụ đề, bấm nút **Lồng tiếng Việt** ở thanh điều khiển của player (hoặc nút **Bật lồng tiếng Việt** trong popup của tiện ích).
